## [Unreleased]

### Added

- Initial project setup: the `LoadingFX_Dev` sample project (UE 5.5) and the `LoadingFX` plugin skeleton with the `LoadingFX`, `LoadingFXLoader` and `LoadingFXBridge` runtime modules.
- Prototype spinner materials `M_LoadingSpinner`, `M_LoadingIcon` and `M_LoadingBoxes` (plus `MF_GLSLMod` and `MF_SdRoundBox2D`), generated by Python builder scripts with the local-only `DevMaterialTools` plugin.
- `M_LoadingBars`: the classic radial-bar spinner (rounded bars, a fade that runs clockwise). Its anti-aliasing width comes from the screen derivatives of the distance field (`fwidth`) rather than from the widget size.
- `M_LoadingArc`: a single rounded arc that stretches and shrinks while it turns. `Speed` sets the steady rotation and `StretchSpeed` the stretch cycle; `ArcMin` / `ArcMax` set the shortest and longest arc in turns.
- `M_LoadingComet`: a round head running clockwise around a ring, with a tail that thins and fades out over one full turn. The tail fades in opacity, so it stays clean on light backgrounds.
- `M_LoadingDots`: a row of dots (three by default) that swell and brighten one after another from left to right, then rest. It suits wide and small places such as buttons.
- `M_LoadingDualArc`: two pairs of opposite arcs on an outer and an inner ring, turning in opposite directions, in one color. `InnerSpeedRatio` sets the inner ring's speed relative to `Speed`.
- `M_LoadingSegments`: a ring of rounded segments that light up one by one clockwise from 12 o'clock, then go out in the same order. Unlit segments stay faintly visible (`BrightMin`); `Gap` sets the space between segments.
- `M_LoadingTimer`: a pie inside a thin ring that fills clockwise from 12 o'clock, then empties in the same direction, like a timer. `RingOpacity` fades the ring independently.
- `M_LoadingHourglass` (with `MF_SdSegment2D`): sand runs from the top bulb into the bottom one with a thin falling stream, then the glass turns over clockwise and starts again. It shrinks a little while it turns, so it stays close to its resting size.
- `M_LoadingBounce` (with `MF_SdEllipse2D`): a ball that bounces on a floor and flattens while it touches it, over a shadow that shrinks and fades as the ball rises.
- `MF_SpinnerCoords` and the material contract: every bundled spinner uses centered, aspect-corrected coordinates, real time (`Time` with Ignore Pause), multiplies `VertexColor` into its output and shares a default footprint (ring layouts touch a circle of radius 0.8, grid layouts a square of half-width 0.72).
- `ULoadingFXSettings` (Project Settings > Plugins > LoadingFX): loading icon material, size, placement, tint and z-order. The effective material is added to every cook through `FGameDelegates::ModifyCookDelegate`.
- `ULoadingFXIconSubsystem`: reference-counted loading icon (`Acquire` / `Release` handles, optional auto-release when an owner object is destroyed, `OnVisibilityChanged`). The icon is viewport content, so it survives map travel, and while it is visible a blocking map load is rendered through MoviePlayer with the icon as the loading screen. MoviePlayer is unavailable in the editor and PIE, so the icon freezes there during blocking loads. Console: `LoadingFX.Icon.Show`, `LoadingFX.Icon.Hide`, `LoadingFX.Icon.Dump`.
- The loading icon subsystem preloads the icon material asynchronously when it initializes. Loading the material also starts precaching its PSOs, so showing the icon for the first time neither loads the material on the game thread nor compiles its pipeline states. An `Acquire` made before the preload has finished waits for that load, so the icon still appears at once.
- `SLoadingFXSpinner`: Slate widget that draws a spinner material at a given size and tint.
- `ULoadingFXSpinner` (UMG "LoadingFX Spinner", palette category LoadingFX): material (empty = the project's loading icon material), color and opacity, size, `SetOpacity`, and `GetDynamicMaterial` for per-widget parameter changes such as `PrimaryColor` or `Speed`.
- `ULoadingFXLoaderSubsystem` (`LoadingFXLoader` module): loads soft object and soft class references in the background, with progress and cancel, or synchronously. The loaded assets stay in memory until the load is released or its owner object is destroyed (the Blueprint nodes default the owner to the calling object). Blueprint: the Load Assets Async node (On Progress / On Completed / On Canceled, cancelable), Load Assets Sync, Release Loaded Assets, Release All Loaded Assets. Progress counts requested assets. Console: `LoadingFX.Loader.Dump`.
- Every load can ask for the loading icon (`bShowLoadingIcon`): the `LoadingFXBridge` module shows the icon while the load runs. A sync load also keeps an icon that is already requested animating while the game thread is blocked (on a black screen, through MoviePlayer).
- `ULoadingFXIconSubsystem::BeginBlockingSection` / `EndBlockingSection` and `FLoadingFXBlockingScope` (C++): keep the loading icon animating through any work that blocks the game thread, if the icon is requested.
