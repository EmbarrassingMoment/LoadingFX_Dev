## [Unreleased]

### Added

- Initial project setup: the `LoadingFX_Dev` sample project (UE 5.5) and the `LoadingFX` plugin skeleton with the `LoadingFX`, `LoadingFXLoader` and `LoadingFXBridge` runtime modules.
- Prototype spinner materials `M_LoadingSpinner`, `M_LoadingIcon` and `M_LoadingBoxes` (plus `MF_GLSLMod` and `MF_SdRoundBox2D`), generated by Python builder scripts with the local-only `DevMaterialTools` plugin.
- `MF_SpinnerCoords` and the material contract: every bundled spinner uses centered, aspect-corrected coordinates, real time (`Time` with Ignore Pause) and multiplies `VertexColor` into its output.
- `ULoadingFXSettings` (Project Settings > Plugins > LoadingFX): loading icon material, size, placement, tint and z-order. The effective material is added to every cook through `FGameDelegates::ModifyCookDelegate`.
- `ULoadingFXIconSubsystem`: reference-counted loading icon (`Acquire` / `Release` handles, optional auto-release when an owner object is destroyed, `OnVisibilityChanged`). The icon is viewport content, so it survives map travel, and while it is visible a blocking map load is rendered through MoviePlayer with the icon as the loading screen. MoviePlayer is unavailable in the editor and PIE, so the icon freezes there during blocking loads. Console: `LoadingFX.Icon.Show`, `LoadingFX.Icon.Hide`, `LoadingFX.Icon.Dump`.
- `SLoadingFXSpinner`: Slate widget that draws a spinner material at a given size and tint.
- `ULoadingFXSpinner` (UMG "LoadingFX Spinner", palette category LoadingFX): material (empty = the project's loading icon material), color and opacity, size, `SetOpacity`, and `GetDynamicMaterial` for per-widget parameter changes such as `PrimaryColor` or `Speed`.
